## About
An introduction to SQL, from foundational concepts to slightly more advanced techniques, using Google BigQuery as the practical platform.

This module covers data filtering, NULL handling, table joins, result combining, and SQL functions.


## Learning Objectives

*You will be able to:*

* Filter rows using `WHERE` and filter groups using `HAVING`.
* Handle NULL values using `IS NULL` and `IS NOT NULL`.
* Join multiple tables using `INNER JOIN` and `LEFT JOIN`.
* Combine data using `UNION` and `UNION ALL`.
* Use common SQL functions for math calculations and string manipulation.

## Prerequisites
- Familiarity with data types (e.g., strings, integers, floats, booleans)
- Able to use Google BigQuery to access data via SQL.
- Write and execute a SQL query, including `SELECT`, `FROM`, `LIMIT`, and `DISTINCT`.
- Familiar with `ORDER BY`, aliasing tables, and introductory aggregate functions (`MIN`, `MAX`, `SUM`, `AVG`, and `COUNT`).
- Understand the order of operations in SQL.
